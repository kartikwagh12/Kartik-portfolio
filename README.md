# Kartik Wagh — Personal Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `assets/css/style.css` — design and responsive styles
- `assets/js/script.js` — mobile navigation and current year

## Publish with GitHub Pages
1. Open your `Kartik-portfolio` repository.
2. Upload all files and folders from this project. Keep the folder structure unchanged.
3. Make sure `index.html` is in the repository root (not inside another folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then Save.

## Before publishing
- Check the project descriptions and update them to match your actual progress.
- Add a real resume PDF only when you have one. The current page says it is coming soon.
- Add a contact method only when you are ready to publish it.
